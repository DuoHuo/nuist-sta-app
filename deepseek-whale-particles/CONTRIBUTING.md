# 贡献指南

感谢有兴趣改进这个项目！它是纯静态页面，所以流程很轻 —— **没有构建、没有依赖、没有测试框架**。

## 本地运行

```bash
# 方式一：直接打开（file:// 下功能完全正常，因为没有任何网络请求）
start index.html

# 方式二：静态服务
python -m http.server 8000
```

改完刷新浏览器即可，没有任何编译步骤。

## 代码风格

- `whale.js` 使用 **ES5 语法**（`var` / 函数声明），不用 `import` / `export` / 箭头函数 —— 保持"打开就能跑、无需转译"。单个 IIFE 内按 `CONFIG → 工具 → 采样 → 物理 → 绘制 → 启动` 分段，段间用 `/* ==== */` 注释分隔。
- 注释写中文，说明**为什么**这么做（尤其是魔数背后的物理含义），而不只是复述代码。
- 新增可调参数请放进 `CONFIG`，并在 README 的参数表里补一行。

## 调参建议

`CONFIG` 里的示例：

- 粒子更密/更疏：`basePoints`（受 `maxPoints` 限制）
- 轮廓更锐利：调小 `edgeFalloffRef`（边缘权重更集中）；更柔和则调大
- 推得更开：调大 `push` 与 `maxPush`；"推开的范围"由 `influence` 控制
- 冲击波更猛：`burstPower`（与 `burstRadius` 搭配）

> ⚠️ 改力的大小后请**实测一下手感**，不要只凭数值直觉。本项目的力参数曾经因为量纲估算错误而弱了约 10 倍（划过时粒子只动 5px，几乎看不出来）。判断标准：常速划动（约 600px/s）应该有 20–30px 的明显偏移。

## 改动前请自测

用浏览器打开页面，逐项确认：

1. 鲸鱼形状完整可辨，没有明显的空腔或外溢的杂点；
2. 划过时粒子被拨开，移开后约 0.3–0.5s 内聚拢回位；
3. 缩放窗口、切到别的标签页再切回来，画面不炸、不卡；
4. 控制台无报错；`__whale.count` 与预期相符；
5. 移动端模拟器（或真机）上粒子数已自动降低，横划不会带动页面滚动。

## 提交 PR

- 一个 PR 只做一件事，描述里写清"改了什么 / 为什么 / 怎么验证的"。
- **画面相关的改动请附截图或录屏** —— 这是纯视觉项目，评审主要靠看。
- 如果想加自动化测试，欢迎，但请保持"零依赖"：不要引入 npm 包（尤其不要 `canvas`/`jsdom` 这类原生模块）。可参考的思路是用最小桩对象把物理函数抽出来在 Node 里跑，见 README「参数标定与验证」一节。

## 商标

`index.html` 里的鲸鱼轮廓来自 DeepSeek 官方图标。请勿在本项目中新增官方 Logo 图片、字体或声称官方关联。只改代码、不动标识是最省事的做法。

保持友善、对事不对人。技术分歧用数据和截图说话。
