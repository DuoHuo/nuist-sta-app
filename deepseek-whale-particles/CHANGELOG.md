# Changelog

本项目的所有重要变更都记录在此文件。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.0.0] - 2026-09-17

首个版本：纯静态 Canvas 2D 粒子鲸鱼。

### 新增

- 从 DeepSeek 官方鲸鱼图标（50×50 SVG path）运行时栅格化出形状母版，无需任何预烘焙资源或网络请求。
- 两遍 Chamfer 距离场 + 距离加权拒绝采样：轮廓处粒子密度约为内部 4–5 倍，鲸鱼外形由粒子自行"描边"。
- 粒子绕家庭位置做正弦呼吸漂移；光标划过时按「光标速度 × 距离柔化核」推开粒子，叠加切向涡流与尾迹拖拽，松手后弹簧阻尼回位。
- 点击 / 轻触冲击波，半径内粒子获得径向瞬时速度。
- 键盘操作：`←→↑↓` / `WASD` 移动光标，`空格` / `Enter` 触发爆开。
- 空间网格加速光标邻域查询；96 个颜色桶批量绘制；光斑贴图预渲染。
- 静默降级：`Path2D` 缺失时走内置的极简 SVG 路径解析器；移动端自动降低粒子数；尊重 `prefers-reduced-motion`。
- 沿身体横向的靛蓝→青渐变配色；靠近光标或被推开的粒子自动升档高亮。

### 变更

- 交互力参数经离线物理仿真标定：`push` 由 `4300` 提升到 `38000`、`maxPush` 由 `1500` 到 `6500`、`burstPower` 由 `8300` 到 `1350000`、`maxStretch` 由 `0.45` 到 `0.7`。修正前 551px/s 划过时粒子仅偏移约 5px（几乎不可见），修正后常速划动约 23.7px、慢划约 72.8px、冲击波约 51.9px。
- 修复 `build()` 早于 `layout()` 执行导致初始粒子数恒被夹到下限（1500）的问题：现在先确定视口尺寸，再按屏幕面积计算粒子数。
- 距离场衰减尺度改为随母版分辨率等比缩放（`edgeFalloffRef`），换分辨率不会改变疏密手感。
