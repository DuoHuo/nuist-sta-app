# DeepSeek 鲸鱼 · 粒子交互

> 纯静态 Canvas 2D 粒子鲸鱼：用 DeepSeek 官方鲸鱼轮廓做距离场加权采样，光标划过时粒子被拨开，移开后弹簧阻尼回位聚拢。

**零依赖 · 零构建 · 零网络请求** —— 一个 HTML + 一个 CSS + 一个 JS，克隆下来双击 `index.html` 就能跑。

## 实现原理

整条链路只有五步，全部在浏览器里运行时完成，没有任何预烘焙资源：

**1) 轮廓 → 母版位图**
`index.html` 里内联了一条 50×50 viewBox 的官方鲸鱼路径（4 段子路径：身体 + 鱼鳍 + 眼睛 + 尾巴镂空）。用 `Path2D` 把它画进一张 380×380 的离屏 canvas，读回 `ImageData`，得到"哪些像素在鲸鱼内部"的布尔掩码。路径只用到 `M` / `L` / `C` / `Z`，所以对没有 `Path2D` 的浏览器保留了一个约 40 行的极简解析器兜底。

**2) 距离场**
对掩码跑两遍 Chamfer 距离变换，得到每个内部像素到最近轮廓边缘的近似欧氏距离。

**3) 距离场加权采样（关键一步）**
采样概率按 `exp(-d / falloff)` 随距离衰减：

- 42% 的粒子预算在整个内部**均匀**抽取 → 负责体积感；
- 其余 58% 按上述权重做拒绝采样 → **贴在轮廓边缘**，把鲸鱼的外形"描"出来。

实测密度曲线（母版像素为单位的相对密度）：

| 到边缘距离 | 0–2px | 6–8px | 12–14px | 18–20px | 24–26px |
| --- | --- | --- | --- | --- | --- |
| 相对密度 | 0.397 | 0.225 | 0.118 | 0.097 | 0.093 |

即**轮廓处比身体内部密约 4–5 倍**：远看轮廓锐利，近看内部是通透的粒子雾。

**4) 光标推挤物理**
每个粒子有"家庭位置"，平时绕它做慢速正弦呼吸漂移（整只鲸鱼像在游动）。光标靠近时施加推力：

```
推力 = push × (0.55 + velocityPush × 光标速度归一化) × 距离柔化核
v += 推力 / 60                     // 每帧给粒子的速度增量
```

距离柔化核用软化项 `d² + 200` 避免近距离除零炸开，并额外叠加两项细节：

- **切向涡流**：粒子绕光标两侧滑走，而不是直直地弹开；
- **尾迹拖拽**：被推开的粒子顺着划动方向被带走一点，形成"水路"感。

松手后由弹簧阻尼（`stiff=52`, `damp=7.5`）回位；位移另有硬上限 `influence × maxStretch`，防止极端甩动把粒子扔飞。

**5) 绘制**
粒子光斑预渲染成一张径向渐变贴图，之后每帧只做位图拷贝；按 `(16 个横向色带 × 6 档亮度)` 分 96 桶批量绘制，一批只切一次 `fillStyle`；色带沿鲸鱼身体从头部深靛蓝渐变到尾尖亮青。靠近光标 / 被推开的粒子自动升到高亮档，所以"被拨开的地方会亮起来"。

## 参数标定与验证

交互力的大小最初是拍脑袋定的，实测后发现**太弱**（551px/s 划过时粒子只偏移约 5px，肉眼几乎不可见；点击冲击波只有 0.1px/帧）。于是把 `whale.js` 里真实的 `collect` / `applyPush` / `burst` 三个函数原样抽到 Node 里，用桩 DOM 跑离线仿真，扫描参数后标定成现在这组值：

| 划动速度 | 粒子峰值偏移 |
| --- | --- |
| 200–400 px/s（慢划） | 72.8px（安全上限） |
| 600 px/s（常速） | 23.7px |
| 1500 px/s（快划） | 10.8px |
| 点击冲击波 | 51.9px |

慢划反而推得更开，因为在影响圈里停留更久 —— 这是物理上自然的结果，不是刻意做的曲线。

### 几何自检

想自己确认"粒子确实是照着轮廓铺的"，可以把 `index.html` 里那条路径的 `d` 属性取出来，用任意 SVG 栅格化方式打印成 ASCII/图片对比。采样逻辑本身依赖浏览器 canvas，所以仓库里没有内置自动化测试脚本 —— 上面表格里的数字都来自一次性脚本，跑完即弃。

## 配置项

所有可调参数集中在 `whale.js` 顶部的 `CONFIG` 对象：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `basePoints` | `7200` | 1920×1080 上的基准粒子数，按屏幕面积线性伸缩 |
| `minPoints` / `maxPoints` | `1500` / `11000` | 粒子数上下限 |
| `fillRatio` | `0.42` | 预算中用于填充内部的占比，其余给轮廓边缘 |
| `edgeFalloffRef` | `4.5` | 边缘加权衰减尺度（按母版尺寸等比缩放） |
| `sizeFactor` | `0.68` | 鲸鱼边长 ≈ `min(视口宽, 视口高) × 该系数` |
| `driftAmp` / `driftSpeed` | `1.9` / `0.55` | 呼吸漂移幅度与速度 |
| `stiff` / `damp` | `52` / `7.5` | 回位弹簧刚度与阻尼 |
| `influence` | `104` | 光标影响半径（px），小屏自动缩放 |
| `push` / `maxPush` | `38000` / `6500` | 基础推力 / 单粒子每帧推力上限 |
| `velocityPush` | `0.95` | 光标速度对推力的加成 |
| `swirl` / `wake` | `0.28` / `0.45` | 切向涡流 / 尾迹拖拽强度 |
| `maxStretch` | `0.7` | 位移硬上限 = `influence × 该系数` |
| `burstPower` / `burstRadius` | `1350000` / `176` | 点击冲击波的强度与半径 |
| `trailAlpha` | `0.5` | 每帧背景清洗不透明度（越小拖尾越长） |
| `spriteScale` | `2.8` | 光斑贴图相对粒子半径的尺寸 |

配色在 `GRADIENT_STOPS` 里（`u=0` 是鲸头，`u=1` 是尾尖），改这五个色值就能整体换肤。

## 兼容性与无障碍

- Canvas 2D + ES5 语法，无 `import` / 无构建产物；`Path2D` 缺失时自动走内置解析器。
- `devicePixelRatio` 上限取 2，避免 4K/Retina 上无谓地填满像素。
- 尊重 `prefers-reduced-motion: reduce`：漂移幅度降到 0.5px、闪烁几乎关闭、拖尾改为硬清屏。
- 支持键盘操作与 `空格` 触发，不依赖鼠标。
- 移动端自动把粒子数降到 2400 以内。

## 性能

- **空间网格**：粒子按"家庭位置"分桶，光标附近查询只遍历相邻桶，单帧开销与影响圈内的粒子数相关，而不是总粒子数。
- **分桶绘制**：96 个颜色桶顺序绘制，避免逐粒子切换绘图状态。
- **贴图预渲染**：光斑只生成一次，绘制阶段全是 `drawImage`。
- 帧率跟随 `requestAnimationFrame`，单帧 `dt` 上限 0.05s（切回标签页不会"暴走"）。

## 已知限制

- `applyPush` 的推力按固定 1/60 步长施加，因此**在 120Hz 屏幕上单次划过的推力约为 60Hz 的两倍**（视觉上更夸张，不影响稳定性）。要严格帧率无关，可以把 `0.016` 换成真实 `dt` 并重做标定。
- 网格按家庭位置建立，位移超过一个格子加外扩边距的粒子当帧可能取不到 —— 实际影响极小，且 `maxStretch` 已把位移限制在安全范围内。
- 阻力/涡流参数是手感调优的结果，没有物理单位含义。
